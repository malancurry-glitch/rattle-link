Best practices

Small things that make 2FA safer in production.

Use TOTP secrets server-sideGenerate and store a secret on the backend, ideally encrypted at rest.
Rate-limit verificationLock or slow repeated invalid 2FA attempts to reduce brute-force risk.
Invalidate old recovery codesRegenerate recovery codes as a new set and revoke any previous unused list.
Require 2FA after password resetTrusted-device memory should be revoked after password changes or sensitive account updates.
